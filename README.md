# Адиля

Одностраничная открытка: несколько тёплых слов для одного конкретного человека.
Без повода, без даты — просто потому что хотелось сказать.

## Стек

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 4
- Framer Motion 11

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который выведет Vite (обычно http://localhost:5173).

Другие команды:

```bash
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # локальный просмотр собранной версии
npm run typecheck  # только проверка типов
```

## Дизайн

Тёмная тема, но не нейтрально-чёрная: фон тёплый почти-чёрный, как бумага
при настольной лампе. Сверху по центру лежит слабый тёплый свет, к краям
лист затемняется.

Идея — печатная карточка, на которой от руки дописаны детали. Отсюда три
шрифта, и у каждого своя роль:

| Шрифт | Роль |
| --- | --- |
| **Cormorant Garamond** | печатное: имя, заголовки, само послание |
| **Neucha** | рукописное: пометки, подпись, номера обрывков |
| **Golos Text** | основной текст карточек и подписи |

Палитра приглушённая, без неона и холодных тонов: фон `#1A1614`, три оттенка
бумаги `#332E2A`, `#2A2420` и `#241F1C`, чернила `#EDE6DC`, кромка листа
`#4A3F37`, акценты — пыльная роза `#C9A9A4`, терракота `#C97F55` и мягкое
золото `#C6A15B`. Контраст проверен на каждом фоне отдельно: весь текст
даёт от 5,1 до 13,2 при норме WCAG AA 4,5.

Что делает страницу рукотворной, а не шаблонной:

- восемь обрывков отличаются друг от друга всем: размером, тремя оттенками
  бумаги, восемью разными наборами скруглений, наклоном от −2,3° до 2,5°
  и четырьмя типами края — сплошная рамка, пунктирная, точечная и **рваный
  край** (зубцы снизу, тень повторяет силуэт через `drop-shadow`);
- часть листов приклеена бумажным скотчем, часть прошита пунктирным швом;
- бумага дана двумя слоями текстуры — мелкое зерно и вытянутое волокно
  (на тёмном фоне они работают как `overlay`, иначе не видны), плюс неровные
  водяные разливы вместо ровных кругов;
- заголовки подчёркнуты прочерчивающимся штрихом, на полях — нарисованные
  искры, крестики и петельки, стрелка вниз и разделитель нарисованы линией,
  а не собраны из блоков;
- композиция намеренно не осевая: заголовок раздела сдвинут влево, коллаж
  вправо, послание выключено влево как в настоящем письме, а подпись стоит
  справа; буквы имени сидят чуть криво;
- карточки выходят вразнобой: у каждой своя задержка, длительность, высота
  подъёма и сила начального доворота — от 20 до 46 px и от 2,4 до 4,6 крат.

Если в системе включено «уменьшить движение», анимации упрощаются до
прозрачности, а наклон, рамки и текстуры остаются.

## Структура

```
src/
├── components/
│   ├── Background.tsx       # тёмный лист: разливы, свет лампы, текстуры
│   ├── Doodles.tsx          # рукописные SVG: штрихи, стрелка, искры, скотч
│   ├── Ornament.tsx         # разделитель из двух штрихов и петельки
│   ├── Hero.tsx             # имя, «ты лучшая подруга», приветствие
│   ├── Compliments.tsx      # заголовок и коллаж из карточек
│   ├── ComplimentCard.tsx   # один обрывок: оттенок, рамка, рваный край
│   ├── Closing.tsx          # послание на отдельном листе
│   └── Footer.tsx           # нарисованная линейка и ссылка наверх
├── data/
│   ├── compliments.ts   # тексты комплиментов
│   └── cardLayout.ts    # размеры, углы, рамки, тени, задержки карточек
├── hooks/
│   └── useReveal.ts     # появление блоков при загрузке и при скролле
├── lib/
│   └── motion.ts        # общая кривая и варианты появления
├── App.tsx
├── main.tsx
└── index.css            # палитра, текстуры, утилиты рваного края и шва
```

## Как менять содержимое

- **Комплименты** — `src/data/compliments.ts`. Количество можно менять:
  оформление берётся из `cardLayout` по кругу, вёрстка перестроится сама.
- **Как выглядят обрывки** — `src/data/cardLayout.ts`: наклон, скругления,
  отступы, тень, оттенок бумаги, тип края (`solid | dashed | dotted | torn`),
  скотч или шов, задержка и характер появления.
- **Приветствие и послание** — тексты в `Hero.tsx` и `Closing.tsx`.
- **Имя** — константа `NAME` в начале `Hero.tsx`; разнобой букв задаётся
  таблицей `LETTER_JITTER` там же.
- **Палитра, шрифты, текстуры** — блок `@theme` в `src/index.css`.
  Форма рваного края — утилита `.torn` там же.

Если правишь рваный край, помни: зубцы занимают нижние 9% высоты, поэтому
у таких карточек увеличен нижний отступ (`pb-10`/`pb-11`) — текст не должен
заходить под разрез.

Шрифты подключены с Google Fonts. Без интернета страница откроется на системных
запасных шрифтах — вёрстка от этого не поедет, но характер потеряется.
