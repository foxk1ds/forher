# Адиля

Одностраничная открытка: несколько тёплых слов для одного конкретного человека.
Без повода, без даты — просто потому что хотелось сказать.

## Стек

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 4
- Framer Motion 11

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который выведет Vite (обычно http://localhost:5173).

Другие команды:

```bash
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # локальный просмотр собранной версии
npm run typecheck  # только проверка типов
```

## Дизайн

Идея — печатная карточка, на которой от руки дописаны детали. Отсюда три шрифта,
и у каждого своя роль:

| Шрифт | Роль |
| --- | --- |
| **Prata** | печатное: имя, заголовки, само послание |
| **Neucha** | рукописное: пометки, подпись, номера обрывков |
| **Golos Text** | основной текст карточек и подписи |

Палитра припылённая, без чистой «молочности»: лист `#EBE0D0`, обрывки двух
оттенков бумаги `#F3EADB` и `#E5D7C1`, чернила `#2C2823`, акценты — пыльная роза,
терракота и мягкая олива. Все три ступени текста и акцентный цвет проверены на
контраст WCAG AA на обоих оттенках бумаги (от 4,9 до 12,3).

Что делает страницу рукотворной, а не шаблонной:

- восемь карточек отличаются друг от друга размером, углами скругления
  (все восемь — разные), наклоном от −2,2° до 2,4° и мягкими тенями,
  смещёнными в сторону, как от света слева сверху;
- часть обрывков приклеена бумажным скотчем, часть прошита пунктирным швом;
- бумага дана двумя слоями текстуры: мелкое зерно и вытянутое волокно,
  плюс неровные водяные разливы вместо ровных кругов;
- заголовки подчёркнуты прочерчивающимся штрихом, на полях — нарисованные
  искры и крестики, стрелка вниз и петелка в разделителе нарисованы линией,
  а не собраны из элементов;
- буквы имени сидят чуть криво и появляются вразнобой, карточки тоже
  выходят с разными задержками и доворачиваются каждая к своему углу.

Если в системе включено «уменьшить движение», анимации упрощаются до
прозрачности, а наклон и текстуры остаются.

## Структура

```
src/
├── components/
│   ├── Background.tsx       # лист бумаги: разливы и два слоя текстуры
│   ├── Doodles.tsx          # рукописные SVG: штрихи, стрелка, искры, скотч
│   ├── Ornament.tsx         # разделитель из двух штрихов и петельки
│   ├── Hero.tsx             # имя, «ты лучшая подруга», приветствие
│   ├── Compliments.tsx      # заголовок и коллаж из карточек
│   ├── ComplimentCard.tsx   # один бумажный обрывок
│   ├── Closing.tsx          # послание на отдельном листе
│   └── Footer.tsx           # нарисованная линейка и ссылка наверх
├── data/
│   ├── compliments.ts   # тексты комплиментов
│   └── cardLayout.ts    # размеры, углы, тени и задержки карточек
├── hooks/
│   └── useReveal.ts     # появление блоков при загрузке и при скролле
├── lib/
│   └── motion.ts        # общая кривая и варианты появления
├── App.tsx
├── main.tsx
└── index.css            # палитра, текстуры и утилиты
```

## Как менять содержимое

- **Комплименты** — `src/data/compliments.ts`. Количество можно менять:
  оформление берётся из `cardLayout` по кругу, вёрстка перестроится сама.
- **Как выглядят обрывки** — `src/data/cardLayout.ts`: наклон, скругления,
  отступы, тень, оттенок бумаги, скотч или шов, задержка появления.
- **Приветствие и послание** — тексты в `Hero.tsx` и `Closing.tsx`.
- **Имя** — константа `NAME` в начале `Hero.tsx`; разнобой букв задаётся
  таблицей `LETTER_JITTER` там же.
- **Палитра, шрифты, текстуры** — блок `@theme` в `src/index.css`.

Шрифты подключены с Google Fonts. Без интернета страница откроется на системных
запасных шрифтах — вёрстка от этого не поедет, но характер потеряется.
